### ⌨️CLI

[CLI]: #-cli

为了尽可能轻松地使用存储库提供的所有工具，在存储库的根目录中包含了一个CLI：

```shell
$./run
用法：cli.py[选项]命令[参数]...

选项：
  --帮助显示此消息并退出。

命令：
  用于创建、启动和停止代理的代理命令
  竞技场命令进入竞技场
  用于启动基准测试并列出测试和类别的基准测试命令
  安装程序安装系统所需的依赖项。
```

只需克隆回购，安装依赖项。/运行安装程序，您应该可以开始了！``
