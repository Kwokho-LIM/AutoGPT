## CLI文档

本文档描述了如何与项目的CLI（命令行界面）交互。它包括每个命令的输出类型。请注意，agents stop命令将终止在端口8000上运行的任何进程。``

### 1.CLI的入口点

运行不带任何参数的./run命令将显示帮助消息，其中提供了可用命令和选项的列表。`此外，您可以将--help附加到任何命令，以查看特定于该命令的帮助信息。```

```sh
./run
```

**输出：**

```
用法：cli.py[选项]命令[参数]...

选项：
  --帮助显示此消息并退出。

命令：
  用于创建、启动和停止代理的代理命令
  用于启动基准测试并列出测试和类别的基准测试命令
  安装程序安装系统所需的依赖项。
```

如果您需要任何命令的帮助，只需在命令末尾添加--help参数，如下所示：``

```sh
./run命令——帮助
```

这将显示有关该特定命令的详细帮助消息，包括它接受的任何附加选项和参数的列表。

### 2.设置命令

```sh
./运行安装程序
```

**输出：**

```
安装已启动
安装已完成。
```

此命令初始化项目的设置。

### 3.代理命令

**一个。列出所有代理**

```sh
./run代理列表
```

**输出：**

```
可用代理：🤖
        🐙锻造
        🐙autogpt
```

列出所有可用的代理。

**b.创建新代理**

```sh
./run agent创建my_agent
```

**输出：**

```
🎉创建了新代理“my_agent”并切换到autogpts文件夹中的新目录。
```

创建名为“my_agent”的新代理。

**c.启动代理**

```sh
./run agent启动my_agent
```

**输出：**

```
... （ASCII Art表示代理启动）
[日期和时间][forge.sdk.db][调试]🐛使用database_string初始化AgentDB：sqlite：///agent.db
[日期和时间][forge.sdk.agent][信息]📝从http://0.0.0.0.0:8000启动的代理服务器
```

启动“my_agent”并显示启动ASCII艺术和日志。

**d.阻止特工**

```sh
./run代理停止
```

**输出：**

```
代理已停止
```

停止正在运行的代理。

### 4.基准测试命令

**一个。列出基准类别**

```sh
./run基准类别列表
```

**输出：**

```
可用类别：📚
        📖代码
        📖安全
        📖记忆
        ...（以此类推）
```

列出所有可用的基准类别。

**b.列出基准测试**

```sh
./run基准测试列表
```

**输出：**

```
可用测试：📚
        📖接口
                🔬搜索-测试搜索
                🔬写入文件-测试写入文件
        ...（以此类推）
```

列出所有可用的基准测试。

**c.显示基准测试的详细信息**

```sh
./run基准测试详细信息TestWriteFile
```

**输出：**

```
测试写入文件
-------------

        分类：接口
        任务：将单词“Washington”写入.txt文件
        ...（及其他详情）
```

显示“TestWriteFile”基准测试的详细信息。

**d.启动代理的基准测试**

```sh
./run基准测试启动my_agent
```

**输出：**

```
（有关测试运行时显示的测试过程的更多详细信息）
==============13次失败，1次在0.97秒内通过================...
```

显示“my_agent”上的基准测试结果。
